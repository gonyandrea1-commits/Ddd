# MTPN Calc APK: доступ

`access.json` містить SHA-256 хеш пароля APK, а не відкритий пароль. Не змінюйте назву файлу та шлях.

APK перевіряє файл через інтернет під час першого входу та автоматично раз на 24 години. Після зміни `passwordHash` користувачі мають ввести новий пароль під час наступної успішної перевірки. Без інтернету раніше підтверджений доступ зберігається; перший вхід вимагає інтернету.

## Зміна пароля

1. На комп’ютері запустіть `android-apk/set-apk-password.ps1 -Password 'НОВИЙ_ПАРОЛЬ'` у локальному проєкті калькулятора.
2. Скопіюйте весь вміст створеного `android-apk/apk-access.json`.
3. Відкрийте `calc-apk/access.json` у GitHub, замініть його вміст скопійованим JSON та збережіть commit у гілку `main`.

Не вставляйте відкритий пароль замість хеша. У файлі потрібен ключ `passwordHash` і хеш із 64 шістнадцяткових символів.

Пароль стосується лише версій APK з цим механізмом доступу. Браузерна версія не перевіряє цей файл.
